## Agent 聊天样板的设计决定

实际阅读项目 MASTER.md、前端 AGENTS.md、Apple Layout 的官方 JSON、Google Common layouts、Geist Typography/Button、Vercel 指南及 pi-web-ui 的 MessageList/ChatInput 源码。Apple 的层级、对齐和逐步展开；Google 的窄屏辅助面板；Geist 的字体角色、操作主次及可访问名称用于这里的具体布局。没有复制新框架、另一套状态管理或上游不同的 Enter 行为。具体来源：[Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Google Common layouts](https://developer.android.com/design/ui/mobile/guides/layout-and-content/common-layouts)、[Geist Typography](https://vercel.com/geist/typography)、[Geist Button](https://vercel.com/geist/button)、[pi-web-ui ChatInput](https://github.com/xing-shuyin/pi-web-ui/blob/main/web/src/components/ChatInput.tsx)。Joye Lab / VCP 地址在后续已收到；对应正文和源码的读取范围见本记录末尾。

| 入口或区域 | 必要性与主次 | 本批修改 / 验证 |
| --- | --- | --- |
| 入口标题 | 说明当前任务，不重复品牌 | 删除英文装饰眉题与额外头像；保留一个标题及简短说明 |
| 打开对话 | 返回长期对话历史的次级入口 | 维持原会话身份、草稿传递及 warm loader，32/40px 目标 |
| 聊一聊 / 交给助手做 | 不同授权边界，需要明确选择 | 一组安静控件；切换保留草稿，不自动授予目录权限 |
| 发送 / 授权并开始 | 当前表单唯一主操作 | 语义强调色；窄屏 44px；提交中保留文案并使用原 loading 状态 |
| 完成标准 / 工作目录 / 授权 | 执行前必要的信息与许可 | 校验和 IME 原逻辑保留；字段可滚，主动作仍可操作 |
| 选择项目 / 关于我 | 上下文及来源，不属于发送主动作 | 输入框后集中显示，清楚保留只读讨论说明 |
| 任务记录 | 返回进行中和已完成工作 | 保留真实状态订阅及停止路径；删除空态的虚线装饰卡片 |
| 新建独立对话或多人协作 | 低频独立入口 | 安静显示，复用原入口，没有新增一种模式 |
| 视图 | 有意义的替代内容：对话、轨迹、星空 | 按需展开；删除重复的任务/文件/子 Agent 工具栏 |
| 对话工具 | 管理任务、子 Agent、文件 | 原键盘菜单与单一侧栏；Escape 返回触发钮；草稿保留 |
| 项目运行工具 | 有工作目录时才适用的低频操作 | 从聊天正文移入文件侧栏；修复旧绝对定位导致的重叠 |
| 正文 / 输入框 | 核心工作区域 | 同一 760px 阅读宽度、15px/1.66 正文、小圆角、轻阴影；桌面创意功能保留 |
| 语义颜色 | 内容不应随桌面蓝色皮肤重定义 | 从统一 tokens 派生工作内容别名，保留暗色模式；没有组件品牌色硬编码 |

样板截图覆盖 390/768/1440：入口、已有长对话、授权任务、展开视图、文件侧栏、模型与权限浮层、Room 回归。390×480 检查只是缩短浏览器可视窗口，不是原生移动键盘验收。窗口交通灯的目标尺寸、部分技术文案和其他弹窗仍需后续逐项审查；不把样板候选称为全站设计完成。

本批对应检查：Home/Flow 28 项；Composer/input ownership 47 项；工具菜单及项目动作 11 项；实际演示讨论、授权、停止、继续、资料保存；桌面和窄屏文件布局及键盘焦点。开发期间一次热更新造成错误边界，停止编辑后的稳定页面流程复查通过；不会将它冒充真实后端验收。
